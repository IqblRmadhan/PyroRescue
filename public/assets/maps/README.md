# Map permainan

Semua gambar peta dan bayangan memakai format WebP berukuran
**1600 x 1200 piksel**. Format WebP mempertahankan transparansi dengan ukuran
berkas yang lebih kecil agar browser memuat map dengan cepat.

Sungai transparan menampilkan tekstur air bergerak di bawah peta. Bayangan
tepi tanah berada pada `shadow_level1.webp`, `shadow_level2.webp`, dan
`shadow_level3.webp`.

Level 2 memakai `level2-map.webp` sebagai map dasar dan `level2-maps.webp`
sebagai foreground transparan di atas sprite api serta frame padam.
